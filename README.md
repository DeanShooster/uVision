# uVision

Visual Algorithms, Animations and Motions — watch complex algorithms run step by step, explore living worlds, push and challenge real-time systems and animations around in the browser.

## Demo

Watch the app running in real time:

**[uVision walkthrough](https://youtu.be/yefLjXSmaGM)**

## Scripts

```bash
npm install
npm start
npm test
npm run build
```

`npm start` runs the Vite dev server on port 3000.

## What's here

- **Algorithms** — sorting, pathfinding, and computations (Euclidean, FFT, PageRank), with playback and step explanations.
- **Animations** — The Solar System and City Delivery Map as full-screen scenes.
- **Motion** — interactive systems such as Flock and Ripple Cloth.
